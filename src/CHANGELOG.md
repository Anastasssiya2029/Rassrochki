# История изменений

## [Версия от 15.11.2024] - Редактирование и Удаление Школ

### ✨ Новые возможности

#### Редактирование владельцев школ
- Архитектор может редактировать данные главного администратора любой школы
- Возможность изменения:
  - Имени администратора
  - Email для входа (с проверкой уникальности)
  - Пароля (опционально)
- Форма редактирования с валидацией
- Toast уведомления об успешном обновлении

#### Удаление школ
- Архитектор может полностью удалять школы из системы
- Диалог подтверждения с предупреждением о последствиях
- Каскадное удаление всех связанных данных:
  - Всех клиентов школы
  - Всех платежей
  - Всей истории просрочек
  - Всех пользователей школы
- Кнопки действий на каждой карточке школы

### 🔧 Технические изменения

#### Backend (Node.js)
- Добавлен endpoint `PUT /api/schools/:schoolId` для обновления данных владельца
- Добавлен endpoint `DELETE /api/schools/:schoolId` для удаления школы
- Использование транзакций для атомарности операций удаления
- Проверка уникальности email при изменении
- Хеширование нового пароля с bcrypt

#### Frontend
- Обновлен компонент `SchoolManagement.tsx`:
  - Диалог редактирования с отдельной формой
  - AlertDialog для подтверждения удаления
  - Раздельное состояние для Add/Edit форм
- Обновлен `SchoolSelector.tsx` с функциями `handleEditSchool` и `handleDeleteSchool`
- Добавлены методы в `apiService`:
  - `updateSchool(schoolId, data)`
  - `deleteSchool(schoolId)`
- Иконки Edit и Trash2 из lucide-react

#### Документация
- Создан новый файл `SCHOOL_EDIT_DELETE.md` с подробным описанием функций
- Обновлен `SCHOOL_MANAGEMENT.md` с ссылками на новую документацию

## [Версия от 15.11.2024] - Управление школами для Архитектора

### ✨ Новые возможности

#### Страница управления школами
- Добавлена специальная страница для Архитектора с двумя вкладками:
  - **Выбор школы**: просмотр и выбор школы для работы
  - **Управление**: добавление новых школ и просмотр администраторов

#### Создание школ
- Архитектор может создавать новые онлайн-школы
- Автоматическое назначение главного администратора при создании школы
- Форма создания школы с валидацией всех полей:
  - Название школы
  - Имя администратора
  - Email администратора (с проверкой уникальности)
  - Пароль администратора (минимум 6 символов)

#### Отображение информации о школах
- Карточки школ с полной информацией:
  - Название
  - Дата создания
  - Имя главного администратора
  - Email главного администратора
- Красивый UI в стиле минимализма Apple

### 🔧 Технические изменения

#### Фронтенд
- **Новые компоненты:**
  - Обновлён `SchoolSelector.tsx` с поддержкой управления школами
  - Интеграция `SchoolManagement.tsx` в селектор школ
  
- **API сервис:**
  - Добавлен метод `createSchool()` для создания школ
  
- **Типы:**
  - Расширен интерфейс `School` полями `adminName` и `adminEmail`

#### Бэкенд
- **Новые endpoints:**
  - `POST /api/schools` - создание школы с администратором (только для Архитектора)
  - Обновлён `GET /api/schools` для получения информации об администраторах

- **База данных:**
  - Запросы с JOIN для получения информации об администраторах
  - Транзакции для атомарного создания школы и администратора

#### UI/UX
- Добавлен `Toaster` для отображения уведомлений об успехе/ошибках
- Переключатель между вкладками "Выбор школы" и "Управление"
- Диалоговое окно для создания школы с валидацией
- Плавные анимации и transitions
- Кнопка "К списку школ" в хедере для Архитектора
- Toast уведомления с детальным описанием результата действия
- Автоматическое переключение на вкладку "Выбор школы" после создания новой школы

### 📝 Документация
- Создан `SCHOOL_MANAGEMENT.md` с описанием функционала
- Создан `CHANGELOG.md` для отслеживания изменений

### 🔐 Безопасность
- Проверка роли `architect` для доступа к управлению школами
- Валидация уникальности email администратора
- Хеширование паролей с использованием bcrypt

### 🎨 Дизайн
- Минималистичный стиль в духе Apple
- Градиенты: от `#7B68EE` до `#4F9CF9`
- Hover эффекты и анимации
- Отзывчивый дизайн

### 🐛 Исправления
- Исправлена ошибка с отсутствующим компонентом Toaster
- Восстановлены моковые данные MOCK_USERS в AuthContext
- Добавлена поддержка новых полей в типе School
