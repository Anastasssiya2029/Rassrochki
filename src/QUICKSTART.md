## 📝 Шаг 1: Установите зависимости бэкенда

```bash
cd backend-example
npm install
```

## 🔧 Шаг 2: Настройте окружение

```bash
# Скопируйте файл настроек
cp .env.example .env

# Сгенерируйте JWT секрет
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"

# Вставьте полученную строку в .env как JWT_SECRET
```

## 🗄️ Шаг 3: Создайте таблицы

```bash
npm run init-db
```

Вы увидите:
```
✅ Таблица schools создана
✅ Таблица users создана
✅ Таблица clients создана
✅ Таблица payments создана
✅ Таблица overdue_history создана
```

## 🚀 Шаг 4: Запустите API сервер

```bash
npm run dev
```

Сервер запустится на `http://localhost:3001`

## 💻 Шаг 5: Подключите фронтенд

В корне фронтенда создайте `.env.local`:

```env
REACT_APP_API_URL=http://localhost:3001/api
```

Перезапустите React приложение:

```bash
npm start
```

## 🆘 Помощь

**Ошибка подключения к PostgreSQL?**
- Проверьте firewall
- Убедитесь что порт 5432 открыт
- Проверьте данные в `.env`

**Таблицы не создаются?**
- Проверьте права пользователя в PostgreSQL
- Запустите `npm run init-db` повторно

**Фронтенд не видит API?**
- Убедитесь что API запущен на порту 3001
- Проверьте файл `.env.local`
- Перезапустите фронтенд
