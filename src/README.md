# Сервис учёта рассрочек для онлайн-школ

Интерактивный прототип сервиса для учёта внутренних рассрочек клиентов онлайн-школ в стиле минимализма Apple с 3D дизайном.

## 🚀 Возможности

### Для Архитектора
- 🏛️ Управление всеми школами в системе
- ➕ Создание новых онлайн-школ
- 👨‍💼 Назначение главных администраторов
- ✏️ **Редактирование данных владельцев школ**
- 🗑️ **Удаление школ со всеми данными**
- 🔄 Переключение между школами
- 📊 Просмотр данных любой школы
- ⬅️ Кнопка возврата к списку школ

### Для Администратора школы
- 👥 Управление пользователями (менеджеры, помощники)
- 📋 Просмотр всех клиентов школы
- ✏️ Редактирование данных клиентов
- 📊 Статистика по платежам

### Для Менеджера
- 👤 Работа со своими клиентами
- ➕ Добавление новых клиентов
- 💰 Управление платежами
- 📅 Перенос платежей
- 📊 Календарь платежей

### Для Помощника
- 👀 Просмотр данных клиентов
- 📊 Просмотр календаря платежей

## 🔧 Установка и запуск

### Фронтенд

Приложение уже готово к работе в Figma Make. Для локальной разработки:

1. Убедитесь, что все зависимости установлены
2. Запустите приложение

### Бэкенд (опционально)

Если вы хотите использовать реальную базу данных:

1. Перейдите в папку бэкенда:
```bash
cd backend-example
```

2. Установите зависимости:
```bash
npm install
```

3. Настройте переменные окружения в `.env`:
```env
POSTGRESQL_HOST=194.87.215.84
POSTGRESQL_PORT=5432
POSTGRESQL_USER=gen_user
POSTGRESQL_PASSWORD=XHz-?+<i9P3;wI
POSTGRESQL_DBNAME=data_vrassrochki
JWT_SECRET=your-super-secret-key-change-this
PORT=3001
```

4. Инициализируйте базу данных:
```bash
node init-database.js
```

5. Запустите сервер:
```bash
node server.js
```
