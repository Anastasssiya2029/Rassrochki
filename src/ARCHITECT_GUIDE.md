# Руководство для Архитектора

## Вход в систему

Для входа в систему как Архитектор используйте следующие учётные данные:
- **Email:** `architect@example.com`
- **Пароль:** `architect123`

## Главная страница Архитектора

После входа вы увидите специальную страницу с двумя вкладками:

### 📋 Вкладка "Выбор школы"

Здесь отображаются все онлайн-школы в системе:

**Что вы видите:**
- Список всех школ в виде карточек
- Каждая карточка содержит:
  - 🏫 Иконку школы
  - 📝 Название школы
  - 📅 Дату создания

**Как выбрать школу:**
1. Просто нажмите на карточку нужной школы
2. Вы автоматически перейдёте в режим просмотра этой школы
3. Получите доступ к клиентам, платежам и другим данным школы

### ⚙️ Вкладка "Управление"

Здесь вы можете добавлять новые школы и просматривать информацию об администраторах:

**Что вы видите:**
- Кнопку "Добавить школу"
- Карточки всех школ с расширенной информацией:
  - 🏫 Название школы
  - 📅 Дата создания
  - 👤 Имя главного администратора
  - ✉️ Email главного администратора

## Создание новой школы

### Шаг 1: Откройте форму
1. Перейдите на вкладку "Управление"
2. Нажмите кнопку "Добавить школу"

### Шаг 2: Заполните данные школы
Введите следующую информацию:

#### 🏫 Название школы
- Например: "Онлайн-школа программирования"
- Это поле обязательное

### Шаг 3: Назначьте главного администратора

Укажите данные для входа главного администратора школы:

#### 👤 Имя администратора
- Например: "Иван Иванов"
- Это поле обязательное

#### ✉️ Email администратора
- Например: "admin@school.com"
- Email должен быть уникальным в системе
- Это поле обязательное

#### 🔒 Пароль
- Минимум 6 символов
- Администратор будет использовать этот пароль для входа
- Это поле обязательное

### Шаг 4: Создайте школу
Нажмите кнопку "Создать школу"

**Что произойдёт:**
1. ✅ Система создаст новую школу в базе данных
2. ✅ Автоматически создаст учётную запись главного администратора
3. ✅ Вы увидите уведомление об успешном создании
4. ✅ Новая школа появится в списке

### Возможные ошибки

#### ❌ "Пользователь с таким email уже существует"
- Email администратора должен быть уникальным
- Используйте другой email адрес

#### ❌ "Пароль должен быть минимум 6 символов"
- Придумайте более длинный пароль
- Рекомендуется использовать комбинацию букв и цифр

#### ❌ "Некорректный email"
- Проверьте правильность написания email
- Email должен содержать @ и доменное имя

## Работа со школами

После выбора школы вы получаете полный доступ к:
- 👥 Клиентам школы
- 💰 Платежам и рассрочкам
- 📊 Календарю платежей
- 👤 Управлению пользователями
- 📈 Статистике

### Возврат к списку школ

Чтобы вернуться к списку школ:
1. Нажмите на логотип или название в хедере
2. Или выйдите из системы и войдите снова

## Советы по работе

### 🎯 Организация школ
- Давайте школам понятные названия
- Указывайте реальные email администраторов
- Создавайте надёжные пароли для администраторов

### 🔐 Безопасность
- Не передавайте учётные данные Архитектора третьим лицам
- Меняйте пароли администраторов после первого входа
- Используйте уникальные email для каждой школы

### 📝 Рекомендации
- Регулярно проверяйте список школ
- Следите за актуальностью данных администраторов
- Документируйте созданные школы для удобства

## Структура ролей

### 🏛️ Архитектор (вы)
- Видит все школы в системе
- Может создавать новые школы
- Может назначать главных администраторов
- Имеет доступ к данным любой школы

### 👨‍💼 Главный администратор (назначается вами)
- Управляет своей школой
- Может добавлять менеджеров и помощников
- Видит всех клиентов школы
- Может редактировать данные клиентов

### 👔 Менеджер (назначается администратором)
- Работает только со своими клиентами
- Может добавлять новых клиентов
- Может переносить платежи
- Видит календарь платежей своих клиентов

### 🤝 Помощник (назначается администратором)
- Просматривает данные клиентов
- Не может редактировать данные
- Помогает менеджерам с организацией
